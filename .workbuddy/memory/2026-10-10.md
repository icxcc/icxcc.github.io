### 破坏性变更：blog / notes → collections（rc.165 起）

- `blog`、`notes`、`article` 在类型里已是 `never` / `@deprecated`。
- 主题内置兼容层 `compatBlogAndNotesToCollections()`（dist/node/index.js:469）
  会把旧 `blog` 转成 **`dir: '/'`** 的 post 集合，即把源目录下**所有** md
  都当博客文章（仅排除 notes 目录）。不迁移的话 `web3/`、`preview/`、`about.md`
  会被误收进博客列表和标签页。
- 迁移映射：
  - `blog: {...}` → `collections: [{ type: 'post', dir: 'blog', title, link, ... }]`
  - `notes: { dir, link, notes: [...] }` → 每个 note 一个 `{ type: 'doc', dir, linkPrefix, sidebar }`
  - 原`article: '/article/'` → post 集合的 `linkPrefix: '/article/'`

### 关键坑（locale 下的dir 与 linkPrefix）

- `dir` **相对当前 locale 目录**：英文写 `'blog'` / `'notes/demo'`，**不要**带 `en/`。
- `linkPrefix` **不要**带 locale 前缀（`/en/`），主题内部会 `path.join(locale, linkPrefix)`。
  写成 `/en/demo/` 会被拼成 `/en/en/demo/`。
  参考：主题 issue #710、generateWithPost/generateWithDoc（dist/node/index.js:1408/1435）。

### 环境补充（本轮踩到）

- `pnpm run docs:dev` 放进后台任务时stdout 会被吞（日志 0 字节），
  且 `&` + `run_in_background` 组合下退出码不可靠。改用前台 `timeout N` 跑。
- 预览 dist 产物**不要**用 `npx http-server`：npx 拉包受网络影响会502。
  用 `python -m http.server` 且必须**在 dist 根目录**起
  （资产是根路径 `/assets/`，在子目录起会导致页面全白）。
- 静态服务下截图全白 → 说明 JS 没 hydrate，别误判成渲染 bug。
- 截图 SVG 用 `file://` 直接打开时，**窗口尺寸要大于SVG 自身尺寸**，
  否则会被裁切（误以为元素没渲染）。多尺寸对照用一个临时 html 更直观。
- 无头浏览器访问 `http://localhost` 会被拦（"无法访问此网站"），
  但 `file://` 可以。所以验收走 `pnpm docs:dev` 拿 200 后再截，
  别自己起 http-server ——上轮就是在这上面白耗了几轮。
